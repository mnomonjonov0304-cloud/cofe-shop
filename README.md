# Bean & Brew - Kofe Do'koni Sayti

Zamonaviy, responsiv va chiroyli kofe do'koni veb-sayti. HTML, CSS va JavaScript yordamida yaratilgan.

## Xususiyatlar

- ✅ Zamonaviy va toza dizayn
- ✅ To'liq responsiv (mobil, planshet, desktop)
- ✅ Smooth scroll navigatsiya
- ✅ Mobil menyu
- ✅ Menyu bo'limi
- ✅ Aloqa formasi
- ✅ Animatsiyalar va hover effektlari

## Fayllar tuzilishi

```
coffee-shop/
├── index.html      # Asosiy HTML fayli
├── css/
│   └── style.css   # Barcha stillar
├── js/
│   └── script.js   # JavaScript funksiyalari
└── README.md       # Loyiha haqida
```

## Ishga tushirish

1. Loyiha papkasiga kiring:
```bash
cd coffee-shop
```

2. `index.html` faylini brauzerda oching:
   - Oddiy ikki marta bosish orqali
   - Yoki live server orqali ochish (VS Code Live Server tavsiya etiladi)

## Sahifalar bo'limlari

- **Bosh sahifa** - Hero bo'limi va mashhur ichimliklar
- **Menyu** - Issiq va sovuq ichimliklar narxlari bilan
- **Biz haqimizda** - Do'kon haqida ma'lumot
- **Aloqa** - Manzil, telefon va aloqa formasi

## Texnologiyalar

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- Vanilla JavaScript
- Font Awesome ikonkalari
- Google Fonts (Poppins)
